# Panduan agent

- Baca kriteria di `.scratch/atlas-aset/issues/` dan gunakan istilah di `GLOSSARY.md`.
- Kerjakan satu alur pengguna sampai bisa diuji sebelum lanjut ke alur berikutnya.
- Uji perilaku lewat HTTP dengan SQLite sementara. Cek frontend lewat typecheck, build, dan alur utama di browser.
- Backend adalah sumber data utama. Ubah marker setelah respons simpan atau hapus berhasil.
- Pertahankan pesan validasi di dekat field dan dukung input koordinat dengan keyboard.
- Catat perubahan yang dibantu AI dan pemeriksaan yang benar-benar dijalankan di README.
